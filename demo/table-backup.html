原版采用 2D 精灵与 3D 动画混合显示。这里用原桌布、按钮、静态麻将精灵和真实网格重建本地样例；头像内容使用演示占位。

02　出牌时才临时使用 3D 麻将

ZMJTileAnim.get3DTile() 实例化 3D 牌，并交给 gameHandAnim.play() 播放动作。结束后通过回调恢复静态牌面。本地已将 tile3DPrefabEx/mj02 转换成 Three.js 可读的网格，用来演示这个切换过程。

原版使用 Cocos Creator 2.4.4。本地动作是重新编写的演示，尚未完整移植人物手部动画和原版材质。

03　常驻麻将、按钮和方向盘都是精灵

ZMJTile.init() 将牌身、牌面分别设置到 cc.Sprite。ZMJHandTileCtrl 按 tileStartPos / titleStep 排列手牌；ZMJOutTileRow 使用每张牌的 FrontParam 调整图片、缩放、偏移与倾斜。

本地从场景和预制体读出了三家背牌的角度序列、出牌行参数，以及图集的 rect / rotated 数据。静态牌由 Canvas 绘制，手牌由精灵叠加；尚未逐项移植原版所有 skew 和适配参数。

04　动画与服务器逻辑是另外一层

GameAnimMgr 排队播放动画；ZMJTileAnim 将出牌、碰杠等动作转换成视觉表现。GameLogic 接收牌局消息更新模型。完整洗牌和结算不能仅凭这些前端代码确认。
